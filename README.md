
# Smart Shopping Website

A Smart Shopping Website developed using HTML, CSS and JavaScript.

## Features

- Dynamic product loading using Fetch API
- JSON files for products, categories and pricing
- Category-wise product filtering
- Add to Cart functionality
- Update product quantity
- Remove products from cart
- LocalStorage for cart persistence
- SPA navigation using JavaScript Hash Routing
- Checkout form validation
- Enquiry form validation
- Reusable Header and Footer components

## Technologies Used

- HTML5
- CSS3
- JavaScript
- JSON
- Fetch API
- LocalStorage
- Git and GitHub

## How to Run

1. Clone or download this repository.
2. Open the project in VS Code.
3. Install and use Live Server.
4. Open `index.html` using Live Server.
